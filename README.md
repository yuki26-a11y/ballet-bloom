# Ballet Bloom · 我的芭蕾成长日记

一个为成人芭蕾学习者打造的个人网站，用浅粉与浅紫记录每一次成长。

## 功能

- **成长概览**：累计课时、练习时长、本月次数、衣柜数量，最近课堂时间线、月度日历与照片速览。
- **照片墙**：多图上传、自动压缩、标签分类、大图浏览、说明编辑与删除。
- **课时记录**：记录上课日期、时间、时长、地点、课程类型、老师、当天体服/搭配、衣柜单品与课堂笔记，支持筛选和搜索。
- **我的衣柜**：拍照上传体服、纱裙、打底袜、舞鞋、配饰、外套，按分类管理，建议透明背景 PNG。
- **搭配台**：点选单品放入搭配板，随机搭配、保存多套造型，并可将造型一键关联到课时记录。

## 运行

无需构建，也不需要后端。在项目目录启动任意静态服务器即可：

```bash
python3 -m http.server 8765
```

然后打开 <http://localhost:8765>。

## 在手机上使用

服务器已改为监听所有网卡，手机与电脑连接同一个 Wi-Fi 后，在手机浏览器打开：

```
http://电脑的局域网IP:8765
```

例如当前网络下是 `http://172.16.4.72:8765`。局域网 IP 可能随网络变化，可用 `ipconfig getifaddr en0` 重新查看。电脑需要保持开机且服务器保持运行。

页面已适配手机：底部有五个导航入口，照片、表单和搭配板都能在小屏幕上使用。支持「添加到主屏幕」，添加后会像 App 一样全屏打开：

- iPhone：Safari 底部「分享」→「添加到主屏幕」
- Android：Chrome 右上菜单 →「添加到主屏幕 / 安装应用」

## 数据存储

所有照片、单品图片和文字记录都保存在**当前浏览器的 IndexedDB** 中，刷新或关闭页面不会丢失；图片上传时会自动压缩。数据不会上传到任何服务器，因此建议：

- 使用同一浏览器访问，避免换浏览器后看不到记录；
- 手机和电脑的数据相互独立，不会自动同步；若需跨设备共享同一份记录，需要接入云端存储；
- 定期用浏览器开发者工具导出重要照片备份；
- 清理浏览器站点数据时注意会一并删除本站记录。
